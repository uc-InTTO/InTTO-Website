## Introduction

### What is the Admin Panel?

The **InTTO Admin Panel** is a powerful content management system that allows authorized administrators to manage all aspects of the InTTO website. Through this panel, you can create, edit, and delete content that appears on the public-facing website.

### Who Should Use This Manual?

This manual is specifically designed for:
- **InTTO Administrators** - Staff members managing content
- **Content Managers** - Team members responsible for updates
- **Authorized Personnel** - Anyone granted admin access

### What You Can Do as an Admin

✅ **Manage Startups** - Add, edit, and remove startup profiles  
✅ **Create Content** - Publish news articles and event announcements  
✅ **Update Team** - Maintain team member directory  
✅ **Track IP** - Monitor intellectual property applications  
✅ **View Analytics** - Access website performance metrics  
✅ **Configure Settings** - Adjust site configuration  

### Admin Responsibilities

As an administrator, you are responsible for:
- ✔️ Maintaining accurate and up-to-date information
- ✔️ Following content guidelines and standards
- ✔️ Protecting sensitive data and login credentials
- ✔️ Regularly reviewing and updating content
- ✔️ Ensuring content quality and consistency

### System Requirements

- **Browser:** Chrome, Firefox, Safari, or Edge (latest versions)
- **Screen Resolution:** 1366x768 or higher recommended
- **Internet Connection:** Stable connection required
- **Permissions:** Admin access granted by InTTO

## Getting Started

### Accessing the Admin Panel

#### Step 1: Navigate to Admin Login Page

1. Open your web browser
2. Go to the admin URL: `[Your Website URL]/admin/index.html`
3. You'll see the admin login page

#### Step 2: Login with Your Credentials

1. **Enter your email address** - Must be a registered admin email
2. **Enter your password** - Use the password provided during account setup
3. **Click "Login"** button
4. If credentials are correct, you'll be redirected to the dashboard

#### Important Security Notes

🔒 **Keep credentials secure** - Never share your admin login information  
🔒 **Use strong passwords** - Combine letters, numbers, and special characters  
🔒 **Logout when finished** - Always click "Logout" before closing the browser  
🔒 **Report suspicious activity** - Contact IT immediately if you notice unauthorized access  

### First-Time Login

When you log in for the first time:

1. **Review the dashboard** - Familiarize yourself with the layout
2. **Check your permissions** - Ensure you have access to necessary sections
3. **Update your profile** (if available) - Add contact information
4. **Change your password** - Create a strong, unique password
5. **Explore the interface** - Navigate through different sections

### Navigation Structure

The admin panel sidebar includes:

- **Dashboard** - Homepage with overview and quick stats
- **Startups** - Manage startup profiles
- **News & Events** - Create and edit articles/events
- **Team** - Manage team member profiles
- **IP Applications** - Track intellectual property
- **Metrics** - View analytics and reports
- **Settings** - Configure site settings (if available)
- **Logout** - Sign out of admin panel

### Understanding Access Levels

Admin access is controlled through Firebase:

- **Super Admin** - Full access to all features
- **Content Admin** - Can manage content but not settings
- **Viewer** - Read-only access to analytics

*Your access level determines which features you can use.*

## Managing Startups

### Viewing All Startups

1. **Click "Startups"** in the admin sidebar
2. You'll see a list/table of all startups showing:
   - Startup name
   - Industry/category
   - Status (Active, Inactive, Graduated)
   - Last updated date
   - Action buttons (Edit, Delete)

3. **Use filters to find startups:**
   - Search by name
   - Filter by status
   - Filter by industry
   - Sort by date added

### Adding a New Startup

#### Step 1: Start New Startup Form

1. Click **"Add New Startup"** or **"+ Add Startup"** button
2. The startup creation form will open

#### Step 2: Basic Information

Fill in the required fields:

**Startup Identity:**
- **Startup Name*** - Official business name
- **Alternative Title** - Tagline or alternative name
- **Industry/Category*** - Select from dropdown (e.g., HealthTech, AgriTech, EdTech)
- **Status*** - Choose: Active, Inactive, or Graduated
- **Incubation Status** - Pre-incubation, Incubated, or Graduated

#### Step 3: Description & Details

**About the Startup:**
- **Description*** - Comprehensive overview (200-500 words)
  - What problem does it solve?
  - What is the solution/product?
  - Who are the target customers?
  - What makes it unique?

**Value Proposition:**
- Clear explanation of benefits
- Market differentiation
- Competitive advantages

#### Step 4: Team Information

**Founders & Team:**
- **Founders*** - Names of founders (comma-separated)
  - Example: "John Doe, Jane Smith"
- **Team Size** - Number of team members
- **Key Personnel** - Notable team members and their roles

#### Step 5: Technology & Innovation

**Technical Details:**
- **TRL Level*** - Select Technology Readiness Level (1-9)
  - TRL 1-3: Research/concept phase
  - TRL 4-6: Development/testing phase
  - TRL 7-9: Deployment/market phase

- **Keywords/Tags** - Add relevant keywords (comma-separated)
  - Example: "AI, Healthcare, Diagnostics, Mobile App"

- **Technology Description** - Technical specifications or innovation details

#### Step 6: Impact & Achievements

**Social Impact:**
- **Related SDGs*** - Select applicable Sustainable Development Goals
  - Click checkboxes for SDGs 1-17
  - Multiple selections allowed

- **Social Impact Statement** - Describe the positive impact
  - Communities benefited
  - Environmental benefits
  - Social contributions

**Achievements:**
- Awards and recognitions
- Milestones reached
- Media coverage
- Funding received
- Partnerships established

#### Step 7: Media & Assets

**Logo Upload:**
1. Click **"Upload Logo"** button
2. Select image file (JPG, PNG)
3. Recommended: Square format, 400x400px minimum
4. Logo will be automatically optimized

**Additional Images:**
1. Click **"Upload Images"** or drag files to upload area
2. Select multiple images (up to 10)
3. Recommended: 1920x1080px for best quality
4. Images appear as thumbnails
5. **Reorder:** Drag images to change order
6. **Delete:** Click X on thumbnail to remove

**Video Links:**
- Add YouTube or Vimeo URLs
- Videos will be embedded on startup page

#### Step 8: Contact Information

**Startup Contact Details:**
- **Website URL** - Official website (include https://)
- **Email Address*** - Contact email
- **Phone Number** - Contact number with country code
- **Social Media Links:**
  - Facebook page URL
  - LinkedIn profile URL
  - Twitter handle
  - Instagram profile
  - Other platforms

#### Step 9: Review & Publish

1. **Review all information** - Scroll through the form
2. **Check for errors** - Ensure all required fields are filled
3. **Preview** (if available) - See how it will appear on website
4. **Choose action:**
   - **Save as Draft** - Save without publishing (visible only to admins)
   - **Publish** - Make live on public website immediately

5. Click the chosen button
6. **Confirmation** - You'll see a success message
7. **View on site** - Click link to see published startup

### Editing an Existing Startup

#### How to Edit:

1. **Find the startup** in the startups list
   - Use search or filters if needed

2. **Click "Edit"** button next to the startup name

3. **Modify any field** - The form looks identical to the "Add" form
   - Update outdated information
   - Add new achievements
   - Upload new images
   - Change status

4. **Save changes:**
   - Click **"Update"** to save and keep published
   - Click **"Save as Draft"** to unpublish temporarily

5. **Verify changes** - Check the public website to confirm updates

#### Common Edits:

- **Update status** - Change from Active to Graduated
- **Add achievements** - Include new awards or milestones
- **Update contact info** - New website or email
- **Refresh images** - Add recent photos
- **Update TRL** - As technology advances

### Deleting a Startup

⚠️ **Warning:** Deletion is permanent and cannot be undone!

#### When to Delete:
- Startup is no longer affiliated with InTTO
- Duplicate entry exists
- Company has permanently closed
- Information is outdated and cannot be updated

#### How to Delete:

1. **Find the startup** in the list
2. **Click "Delete"** button (usually red)
3. **Confirm deletion** in the popup dialog
   - Read the warning message
   - Verify you're deleting the correct startup
4. **Click "Confirm" or "Delete"**
5. Startup is immediately removed from database and website

#### Best Practice:
Instead of deleting, consider:
- Changing status to "Inactive" or "Graduated"
- Moving to an archive (if available)
- Saving a backup of information before deletion

### Managing Startup Status

**Status Types:**

1. **Active**
   - Currently in incubation program
   - Receiving active support
   - Featured on website

2. **Inactive**
   - Temporarily paused
   - Not currently active but may resume
   - Still visible on website (depending on settings)

3. **Graduated**
   - Completed incubation program
   - Operating independently
   - Alumni status

**How to Change Status:**
1. Edit the startup
2. Change the "Status" dropdown
3. Update "Incubation Status" if needed
4. Save changes

### Bulk Actions (if available)

Some admin panels support bulk operations:

- **Select multiple startups** - Use checkboxes
- **Apply action:** Export, Change status, Delete
- **Confirm bulk action**

## Managing News & Events

### Viewing All News & Events

1. **Click "News & Events"** in sidebar
2. View list showing:
   - Title
   - Type (News or Event)
   - Status (Draft or Published)
   - Publication date
   - Author
   - Actions (Edit, Delete)

3. **Filter content:**
   - By type (News/Events)
   - By status (Draft/Published)
   - By date range
   - Search by title

### Creating a News Article

#### Step 1: Start New Article

1. Click **"Add News"** or **"+ Create Article"** button
2. Select **"News"** as the type

#### Step 2: Article Content

**Basic Information:**
- **Title*** - Headline (60-80 characters optimal)
  - Make it engaging and descriptive
  - Include key information
  - Use active voice

- **Content*** - Full article text
  - Use the rich text editor for formatting
  - Structure with headings and paragraphs
  - Keep paragraphs short and scannable
  - Include quotes or statistics if relevant

**Rich Text Editor Features:**
- **Bold/Italic/Underline** - Emphasize text
- **Headings** - H2, H3 for sections
- **Lists** - Bulleted or numbered
- **Links** - Add hyperlinks to external resources
- **Quotes** - Block quotes for emphasis
- **Alignment** - Left, center, right

#### Step 3: Publication Details

**Metadata:**
- **Author Name** - Your name or "InTTO Team"
- **Publication Date*** - When it should be published
  - Use today's date for immediate publishing
  - Future date for scheduled content (if supported)
- **Status*** - Draft or Published

#### Step 4: Categorization

**Tags:**
- Add relevant tags (comma-separated)
- Examples: "Innovation", "Research", "Competition", "Workshop"
- Tags help users find related content
- Use 3-7 tags per article

**Related SDGs:**
- Select applicable Sustainable Development Goals
- Check all relevant boxes (SDGs 1-17)
- Shows InTTO's impact alignment

#### Step 5: Featured Image

**Upload Image:**
1. Click **"Upload Featured Image"** button
2. Choose high-quality image (JPG, PNG)
3. Recommended: 1920x1080px (landscape)
4. Image appears at top of article
5. Add **Alt Text** for accessibility
   - Describe image in 5-10 words
   - Helps visually impaired users

**Additional Images:**
- Upload gallery images
- Embedded within article content
- Place using rich text editor

#### Step 6: Review & Publish

1. **Preview** - See how article will look
2. **Proofread** - Check spelling and grammar
3. **Verify links** - Ensure all URLs work
4. **Choose action:**
   - **Save as Draft** - Save without publishing
   - **Publish** - Make live immediately

### Creating an Event

Events follow the same process as news articles, with additional fields:

#### Event-Specific Fields:

**Event Details:**
- **Event Date & Time*** - When the event occurs
  - Use date picker
  - Include start and end time
  - Specify timezone if needed

- **Location/Venue*** - Where it takes place
  - Physical address for in-person events
  - Platform name (Zoom, Google Meet) for virtual events
  - Include room/building number

- **Event Type** - Workshop, Seminar, Competition, Conference, etc.

- **Registration Information:**
  - Registration deadline
  - Registration link/URL
  - Capacity/maximum participants
  - Requirements or prerequisites

- **Event Agenda** - Schedule or program flow
  - Use bullet points or timeline format
  - Include speaker names and topics

- **Contact Person** - Who to contact for inquiries
  - Name, email, phone number

**Event Status:**
- **Upcoming** - Event hasn't occurred yet
- **Ongoing** - Currently happening
- **Completed** - Event has finished
- **Cancelled** - Event was cancelled

### Editing News & Events

1. **Find the article/event** in the list
2. **Click "Edit"** button
3. **Make changes** to any field
4. **Update images** if needed
5. **Click "Update"** to save
6. Changes appear immediately on website

### Publishing Drafts

To publish a draft article:

1. Edit the draft article/event
2. Change **Status** to "Published"
3. Verify **Publication Date** is correct
4. Click **"Update"**
5. Content is now live

### Unpublishing Content

To temporarily remove from website:

1. Edit the published article/event
2. Change **Status** to "Draft"
3. Click **"Update"**
4. Content removed from public site but saved in admin panel

### Deleting News & Events

⚠️ **Warning:** Deletion is permanent!

1. **Find the article/event** in list
2. **Click "Delete"** button
3. **Confirm deletion**
4. Content is permanently removed

**Recommendation:** Instead of deleting, consider unpublishing (save as draft) to preserve the content.

### Managing Event Calendar

If your admin panel includes a calendar view:

- **View by month** - See all scheduled events
- **Drag to reschedule** - Change dates easily (if supported)
- **Color coding** - Different colors for event types
- **Filter view** - Show only certain types

  - Educational background

- **LinkedIn** - Full profile URL

- **ResearchGate** - For academic profiles

- **Other Links** - Personal website, portfolio

**Tips:**

- Verify links work before saving
- Use professional profiles only

#### Step 6: Photo Upload

**Profile Photo:**
1. Click **"Upload Photo"** button

3. **Requirements:**
   - Format: JPG or PNG
   - Recommended size: 400x400px (square)

**Visibility & Order:**
- **Status*** - Active or Inactive

- **Display Order** - Number determining sort order
  - Lower numbers appear first
  - Example: Director (1), Managers (2-5), Staff (6-20)
  - Used to organize team hierarchy

#### Step 8: Save Profile

1. **Review all information**
2. **Check photo** - Ensure proper display
3. **Verify contact info** - Double-check email and phone

1. **Find the member** in team list

3. **Update any information:**

   - Updated bio
   - New photo
   - Changed contact info
4. **Click "Update"** or "Save Changes"

**Method 1: Display Order Numbers**
1. Edit each team member

3. Changes save automatically

When a team member leaves:

1. **Edit their profile**
2. **Change Status to "Inactive"**
3. **Save changes**
4. Profile hidden from website but preserved in database

**Don't delete** - Preserve historical records

### Deleting Team Members

Only delete if:
- Duplicate entry
- Test entry
- Never actually part of team

**To delete:**
1. Click "Delete" button
2. Confirm deletion
3. Profile permanently removed

### User Management

**Managing Admin Users:**

1. **View all admins** - List of authorized users
2. **Add new admin:**
   - Go to Firebase Console
   - Navigate to Firestore Database
   - Open `admins` collection
   - Add new document:
     - **Document ID:** admin email address
     - **Fields:**
       ```
       email: "newadmin@uc.edu.ph"
       role: "admin"
       addedAt: [current timestamp]
       displayName: "Admin Name"
       ```
   - Click "Save"
   - New admin can now log in

## Troubleshooting

### Common Issues

#### Cannot Log In

**Problem:** Login button doesn't work or shows error

**Solutions:**
1. **Verify credentials:**
   - Check email spelling
   - Ensure password is correct
   - Check for caps lock

2. **Check admin status:**
   - Confirm email is in Firebase `admins` collection
   - Verify account hasn't been deactivated

3. **Browser issues:**
   - Clear browser cache and cookies
   - Try incognito/private mode
   - Use different browser
   - Update browser to latest version

4. **Network issues:**
   - Check internet connection
   - Disable VPN temporarily
   - Try different network

5. **Contact IT support** if problem persists

#### Content Not Saving

**Problem:** Changes aren't being saved

**Solutions:**
1. **Check internet connection** - Ensure stable connection
2. **Look for error messages** - Read any displayed errors
3. **Verify required fields** - Ensure all * fields are filled
4. **Check file sizes** - Large files may timeout
5. **Try again** - Sometimes temporary glitch
6. **Refresh page** - But you'll lose unsaved work
7. **Copy content** - Save to text file before retrying

#### Images Not Uploading

**Problem:** Image upload fails or shows error

**Solutions:**
1. **Check file size:**
   - Maximum 10MB per image
   - Compress if necessary

2. **Verify file format:**
   - Use JPG, PNG, or WebP
   - Convert other formats

3. **Check filename:**
   - Remove special characters
   - Use shorter names
   - Avoid spaces (use hyphens)

4. **Try different image:**
   - Test with smaller file
   - Verify image isn't corrupted

5. **Clear cache:**
   - Browser cache may cause issues
   - Refresh page

6. **Check Cloudinary status:**
   - Verify service is operational
   - Check quota/limits

#### Published Content Not Appearing

**Problem:** Published content doesn't show on website

**Solutions:**
1. **Verify status:**
   - Ensure set to "Published" (not "Draft")
   - Check activation date

2. **Clear cache:**
   - Clear browser cache
   - Hard refresh (Ctrl + F5)
   - Wait 1-2 minutes for CDN update

3. **Check data completeness:**
   - Verify all required fields filled
   - Ensure images loaded properly

4. **Inspect for errors:**
   - Open browser console (F12)
   - Look for JavaScript errors

5. **Test in different browser:**
   - Verify it's not browser-specific

#### Slow Performance

**Problem:** Admin panel is slow or unresponsive

**Solutions:**
1. **Check internet speed:**
   - Run speed test
   - Restart router

2. **Close unnecessary tabs:**
   - Limit open browser tabs
   - Close unused applications

3. **Clear browser data:**
   - Clear cache
   - Clear cookies
   - Clear browsing history

4. **Update browser:**
   - Use latest version
   - Try different browser

5. **Reduce image sizes:**
   - Don't upload extremely large files
   - Optimize before uploading

6. **Check system resources:**
   - Close memory-intensive programs
   - Restart computer

#### Can't Delete Content

**Problem:** Delete button doesn't work

**Solutions:**
1. **Check permissions:**
   - Verify you have delete rights
   - Contact super admin

2. **Look for dependencies:**
   - Content may be linked elsewhere
   - Remove references first

3. **Try editing first:**
   - Change status to inactive
   - Then attempt delete

4. **Browser console:**
   - Check for JavaScript errors
   - May indicate technical issue

## FAQ

### General Admin Questions

**Q: How do I become an admin?**  
A: Contact the InTTO Director or IT department to request admin access. They will add your email to the authorized admins list in Firebase.

**Q: Can I have multiple admin accounts?**  
A: No, each admin should have only one account tied to their official email address.

**Q: What if I forget my password?**  
A: Use the "Forgot Password" link on the login page (if available), or contact IT support to reset your password.

**Q: Can I access admin panel from mobile?**  
A: While technically possible, admin panel is optimized for desktop use. Mobile access is not recommended for complex tasks.

**Q: How often should I log in?**  
A: Daily logins are recommended to monitor activity and respond to submissions promptly.

### Content Management Questions

**Q: Can I schedule content for future publication?**  
A: This depends on your system. Some admin panels support scheduling; others require manual publishing at the desired time.

**Q: What happens to draft content?**  
A: Drafts are saved in the database but not visible on the public website. Only admins can see drafts.

**Q: Can I recover deleted content?**  
A: Generally no, unless backups exist. Contact IT immediately if you accidentally delete important content.

**Q: How many images can I upload per startup?**  
A: Typically 1 logo and up to 10 additional images, but check your specific system limits.

**Q: Do I need to optimize images before uploading?**  
A: While the system auto-optimizes, pre-optimizing large images (2MB+) speeds up upload and improves performance.

### Technical Questions

**Q: What browsers are supported?**  
A: Chrome, Firefox, Safari, and Edge (latest versions). Internet Explorer is not supported.

**Q: Why do I see different data than other admins?**  
A: Some data updates in real-time while other data may cache. Try refreshing your browser.

**Q: Can I export data from the admin panel?**  
A: Yes, most sections support export to Excel or PDF. Look for "Export" buttons.

**Q: Is there a mobile app for admins?**  
A: Currently no dedicated mobile app. Use the web-based admin panel from any device.

**Q: How is my data backed up?**  
A: Firebase automatically backs up data. Additional manual backups should be performed regularly.

### Workflow Questions

**Q: Do I need approval before publishing?**  
A: This depends on your organization's policy. Check with your supervisor about approval workflows.

**Q: Can multiple admins edit the same content simultaneously?**  
A: Technically yes, but last save wins. Coordinate with team to avoid overwriting changes.

**Q: How do I know what needs updating?**  
A: Check the dashboard for pending tasks and review content regularly for accuracy.

**Q: Should I delete or inactivate old content?**  
A: Generally inactivate rather than delete to preserve historical records.

### Security Questions

**Q: Is the admin panel secure?**  
A: Yes, it uses Firebase authentication, HTTPS encryption, and restricts access to authorized emails only.

**Q: Can I use public WiFi to access admin panel?**  
A: Not recommended. Use secure, trusted networks only.

**Q: What should I do if I suspect unauthorized access?**  
A: Contact IT support immediately, change your password, and report the incident.

**Q: How long does my session last?**  
A: Sessions typically timeout after 30-60 minutes of inactivity. Always log out manually.
