✨ API Features

Public read-only access. No API keys or tokens required.

📄 Pagination Support

Handle large datasets efficiently with offset and limit parameters.

🎨 WordPress Ready

JSON format optimized for WordPress plugins and importers.

🔍 Advanced Filtering

Filter by date, type, SDG tags, and more.

🖼️ Image URLs Included

💻 Quick Start Examples

JavaScript / Fetch

const response = await fetch('https://uc-intto.com/api/news-events.html?limit=10'); const data = await response.json(); console.log(data.items); // Array of news & events

PHP / WordPress

$response = wp_remote_get('https://uc-intto.com/api/news-events.html'); $data = json_decode(wp_remote_retrieve_body($response), true); foreach ($data['items'] as $item) { // Create WordPress post wp_insert_post([...]); }

Python / Requests

import requests response = requests.get('https://uc-intto.com/api/news-events.html') data = response.json() for item in data['items']: print(item['title'])

📚 Common Use Cases

Get latest 20 news items:

/api/news-events.html?type=news&limit=20

Get events published after Jan 1, 2024:

/api/news-events.html?type=event&since=2024-01-01

Get SDG 9 (Innovation) statistics:

/api/sdg-stats.html?sdg=9&include=startups,news,events

Pagination - Get items 10-20:

/api/news-events.html?limit=10&offset=10
