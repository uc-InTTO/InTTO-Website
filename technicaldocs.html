Introduction

The InTTO Website is a comprehensive web-based platform designed to manage and showcase the innovation ecosystem of the University of the Cordilleras Innovation & Technology Transfer Office. This documentation details the system architecture, installation procedures, usage workflows, and API endpoints. It is intended for administrators, developers, and end-users seeking to understand or integrate with the platform.

System Overview

The platform consists of three main modules:

Public Website

Showcases university startups, news/events, programs, and services to the general public

Admin Panel

Content management system for authenticated administrators to manage all platform content

uColab Platform

Project submission and management portal for innovators and researchers

Key Features

  • Startup Management: Comprehensive startup profiles with SDG alignment, TRL tracking, and multimedia support
  • News & Events: Dynamic content management with categorization and tagging
  • IP Application Tracking: Monitor patents, utility models, and other intellectual property
  • Team Directory: Showcase InTTO team members with social media integration
  • Project Collaboration: uColab platform for project submissions and peer review
  • Real-time Updates: Firebase Firestore for instant data synchronization
  • Image Management: Cloudinary integration for optimized media delivery
  • Responsive Design: Mobile-first approach for all devices

Firestore Collections

The database is organized into the following collections:

Collection Description Access Level
startups Incubated startup information, founders, TRL, SDGs, and media Public read, Admin write
newsEvents News articles and event announcements with images and tags Public read, Admin write
team InTTO team member profiles and social media links Public read, Admin write
ipApplications Intellectual property applications (patents, utility models, etc.) Public read, Admin write
projects uColab project submissions and collaboration data Authenticated users
users User authentication and profile information Owner read/write, Admin read
admins List of authorized admin email addresses Admin only
metrics Analytics and performance metrics Admin only

JavaScript API Methods

Reading Data

import { getFirestore, collection, getDocs, query, where } from "firebase/firestore"; // Get all startups const db = getFirestore(); const startupsRef = collection(db, "startups"); const snapshot = await getDocs(startupsRef); const startups = snapshot.docs.map(doc => ({ id: doc.id, ...doc.data() })); // Query active startups only const q = query(startupsRef, where("status", "==", "active")); const activeSnapshot = await getDocs(q);

Writing Data (Admin Only)

import { doc, setDoc, updateDoc, deleteDoc } from "firebase/firestore"; // Add new startup const newStartupRef = doc(collection(db, "startups")); await setDoc(newStartupRef, { name: "New Startup", status: "active", createdAt: serverTimestamp() }); // Update existing startup const startupRef = doc(db, "startups", startupId); await updateDoc(startupRef, { status: "graduated", updatedAt: serverTimestamp() }); // Delete startup await deleteDoc(startupRef);

Authentication Methods

import { getAuth, signInWithEmailAndPassword, signOut } from "firebase/auth"; const auth = getAuth(); // Admin login async function login(email, password) { try { const userCredential = await signInWithEmailAndPassword(auth, email, password); return userCredential.user; } catch (error) { console.error("Login error:", error); throw error; } } // Logout async function logout() { await signOut(auth); }

Security Architecture

Authentication Flow: All admin pages use auth-check.js middleware that redirects unauthorized users to the homepage.
// Admin authentication check (auth-check.js) import { getAuth, onAuthStateChanged } from "firebase/auth"; import { getFirestore, doc, getDoc } from "firebase/firestore"; // Hide page until verification complete document.documentElement.style.visibility = 'hidden'; async function checkAdminAccess() { const auth = getAuth(); const db = getFirestore(); onAuthStateChanged(auth, async (user) => { if (!user) { // Not logged in - redirect to homepage redirectToHome(); return; } // Check if user is in admins collection const adminRef = doc(db, "admins", user.email); const adminDoc = await getDoc(adminRef); if (!adminDoc.exists()) { // Not an admin - redirect redirectToHome(); return; } // Authorized - show page document.documentElement.style.visibility = 'visible'; }); }

Getting Started

Quick Start: To begin using the admin panel, request admin access from the InTTO team, then log in at /admin/index.html using your authorized email and password.

  2. Dashboard: View system overview and recent activities
  3. Add Startup:

    • Click "Add New Startup"
    • Fill in required fields (name, description, founders, etc.)
    • Upload logo and images
    • Select relevant SDGs

    • Save and publish
  4. Create Event:
    • Navigate to News & Events section
    • Click "Add Event"
    • Enter event details and date
    • Upload event images
    • Add tags and related SDGs

  2. Submit Project:

    • Upload supporting documents

  4. Track Progress: Monitor project status and updates

FAQ

General Questions

Q: Who can access the admin panel?

A: Only authorized users whose email addresses are registered in the Firebase admins collection can access the admin panel. Contact the InTTO team to request admin access.

Q: Is the website mobile-friendly?

A: Yes, the entire platform is designed with a mobile-first approach and is fully responsive across all device sizes.

Q: How are images optimized?

A: The platform uses Cloudinary for automatic image optimization, resizing, and CDN delivery, ensuring fast load times without sacrificing quality.

Technical Questions

Q: What happens if Firebase goes down?

A: Firebase has 99.95% uptime SLA. In rare outages, the website will show cached content where available. Real-time features will resume automatically when service is restored.

Q: Can I export data from the platform?

A: Yes, admins can use Firebase console or custom scripts to export all Firestore data in JSON format for backup or migration purposes.

Q: How do I add a new admin?

A: Use the Firebase console to add a new document to the admins collection with the user's email address as the document ID.

// Add admin via Firebase console or script await setDoc(doc(db, "admins", "newadmin@uc.edu.ph"), { email: "newadmin@uc.edu.ph", role: "admin", addedAt: serverTimestamp() });

Q: How do I customize the website theme?

A: Edit the CSS files in the /css directory. The main color scheme uses CSS variables for easy customization:

:root { --primary-color: #1a472a; --secondary-color: #3d7a52; --accent-color: #2d5a3d; --text-color: #333; --background-color: #f5f5f5; }

Troubleshooting

Q: I can't log in to the admin panel. What should I do?

A: Ensure you are using the correct email and password. Check if your email is registered in the admins collection. Clear browser cache and try again. If issues persist, contact the system administrator.

Q: Images are not uploading. What's wrong?

A: Check your internet connection. Verify that image files are under 10MB and in supported formats (JPG, PNG, WebP). Ensure Cloudinary configuration is correct in the admin panel settings.

Q: The website is loading slowly. How can I fix this?

A: Check your internet connection. Clear browser cache. Ensure images are properly optimized through Cloudinary. Monitor Firebase usage to identify any bottlenecks.

Security Warning: Never commit Firebase configuration keys to public repositories. Use environment variables for production deployments.
